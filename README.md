# workshop-magazine

Magazine HTML/CSS (freeCodeCamp), prêt pour GitLab Pages.

## Utilisation
Ouvrir `index.html` dans un navigateur.

## Déploiement GitLab Pages
Créer un projet GitLab nommé `workshop-magazine`, ajouter les fichiers à la racine du dépôt (y compris `.gitlab-ci.yml`), puis pousser sur la branche par défaut. Vérifier **Build > Pipelines**, puis **Deploy > Pages**.

Les images, polices et icônes sont chargées depuis des services externes : une connexion Internet est nécessaire pour les afficher.
